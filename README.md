# 🛒 Amazon Frontend Clone

A frontend clone of Amazon built using **HTML, CSS, and JavaScript**. This project recreates the shopping experience with multiple pages, including product tracking, checkout, and order management.

## ✨ Features

- 🏠 Amazon-inspired homepage
- 📦 Product tracking page
- 🛍️ Checkout page
- 📋 Orders page
- 🎨 Custom styling using CSS
- ⚡ Interactive functionality using JavaScript
- 🖼️ Product images and visual elements

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Kambhampatimeghana/meghana.git
```

### Run the Project

1. Clone or download the repository.
2. Open the project folder.
3. Open `amazonmain.html` in your browser.
4. Explore the different pages of the Amazon frontend clone.
